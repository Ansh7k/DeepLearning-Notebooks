# Labs — IMD AI/DL Lab Series

University lab submissions for the **Intelligent Mobile Devices (AI/DL)** course during MCA Semester 2.

Each lab applies deep learning concepts to real datasets using TensorFlow and Keras.

| Lab | File | Dataset | Technique | Key Result |
|-----|------|---------|-----------|------------|
| Lab 1 | `MNIST_DecisionTree_Lab1.pdf` | MNIST | Decision Tree (sklearn) | Accuracy: 0.88 |
| Lab 2 | `Wine_Quality_EDA_Lab2.ipynb` | Wine Quality (UCI) | EDA — mean, median, std | Statistical profiling |
| Lab 3 | `CIFAR10_ANN_Lab3.ipynb` | CIFAR-10 | Keras Sequential ANN | Baseline classification |
| Lab 4 | `CIFAR10_ANN_Evaluation_Lab4.ipynb` | CIFAR-10 | ANN + confusion matrix | Classification report |
| Lab 5 | `UNet_Image_Segmentation_Lab5.ipynb` | Oxford IIIT Pet | U-Net, IoU metric | Image segmentation |
| Lab 6 | `GAN_FashionMNIST_Lab6.ipynb` | Fashion MNIST | GAN (Generator + Discriminator) | Generative modeling |
| Lab 7 | `CIFAR10_CNN_Lab7.ipynb` | CIFAR-10 | CNN + EarlyStopping | Improved accuracy over ANN |
| Lab 8 | `LSTM_TextGeneration_Lab8.ipynb` | Gutenberg corpus | LSTM, n-gram sequences | Text generation |
